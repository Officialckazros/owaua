01 / The introduction Useful can have a personality

The group chat.
The after hours.
The everyday.

Somewhere between a conversation partner and the person who remembers there was a plan.

owaua is a small Discord persona bot for actual conversation. Send a DM, or mention it in a server, and it answers in the voice defined by its current persona.

It can work with text and supported image attachments, remember the shape of a conversation, and stream a reply while it is being written. It is not a dashboard full of modules; it is a bot you can talk with.

Start with one message. If you want it in a server, mention it when you want an answer.

02 / The repertoire One bot. Different ways to use it.

Big personality.
Practical talents.

There are only a few moving parts, and each one exists to make the conversation feel more coherent and reliable.

01

DMs and mentions

Talk to owaua directly in a DM, or mention it in a server. Ordinary unmentioned server chat is left alone.

02

Text and images

Ask a question with text or attach a supported image for a reaction or image question.

03

A persona that can change

The complete persona lives in one editable file and is reloaded for every reply, so a persona update does not require a bot restart.

04

Durable memory

Recent messages, rolling summaries, and stable user facts live in SQLite. Restarting the bot does not erase the conversation.

05

Replies that hold together

Requests are serialized, stale requests can be cancelled, temporary failures are retried, and long replies split safely for Discord.

06

A little breathing room

Each user can make 25 AI requests in 45 seconds. When the limit is reached, owaua says when to try again.

The bot responds only when a DM or mention gives it a reason to join in.

04 / Your data Know what stays around

Good company.
Clear boundaries.

Your settings deserve as much attention as the reply.

Conversation messages are stored in a local SQLite database so the bot can keep context across restarts. Recent turns are sent to the model; older turns may become a rolling summary and stable facts.

Set MEMORY_RETENTION_DAYS to prune old raw messages, or keep it at 0 for no automatic pruning. The database can contain private conversation content, so keep the host and backups private.

OpenAI requests use store: false. Background memory summaries avoid passwords, tokens, contact details, exact locations, medical or crisis details, and sexual details.

05 / Getting started From setup to first conversation

Make yourself
at home.

owaua is intentionally simple to use once its Discord and provider settings are configured.

  1. Configure the secrets.

    Set the Discord token and OpenAI key in .env. Keep both out of the repository and logs.

  2. Run the bot.

    Start the process with the project’s documented launcher. It creates the SQLite memory database under data/ and keeps it across restarts.

  3. Start talking.

    Send a DM, or mention owaua in a server. Add an image when useful, and use !nuke N only with the required permission.

06 / Before you ask A little more context

The questions
worth asking.

Does owaua answer every server message?

No. It answers DMs and messages that mention it. Ordinary unmentioned server conversation is left alone.

Why didn’t it answer?

Check that the message was a DM or included a mention, that Message Content Intent is enabled, and that you have not reached the 25-request rolling limit.

Are summaries the same as chat history?

No. Recent messages remain verbatim for context; older messages may be condensed into a summary and stable facts. The retention setting controls raw-message cleanup.

Can I rely on every AI answer?

AI answers can be mistaken or incomplete. Check important details against reliable sources, and review generated drafts before sharing them. A confident answer still deserves a second look.

Where do I report a problem?

For setup help or a reproducible issue, visit the official server. Explain which feature you used and what happened. Do not post account credentials or private conversations in a public support channel.

Can I change the personality?

Yes. Edit the text inside PERSONA in persona.py. The bot reloads that file for the next message.
