01 / the deal it’s a bot. you talk to it.

It’s a bot.
You talk to it.

Most Discord bots wait for a command. This one waits for a message.

owaua is a small persona bot. You DM it, or you mention it in a server, and it answers in whatever voice is sitting in its persona file right now.

It reads text, it can look at pictures, it remembers the conversation, and the reply shows up while it’s still being written. That’s the product. Not a pile of modules with a chatbot taped on.

Start with one message. In a server it stays out of the way unless you ping it.

02 / the kit not a lot of moving parts

What it does.
That’s kinda it.

A handful of parts. All of them exist so the chat doesn’t feel broken or fake.

01

DMs and mentions

Talk in a DM, or ping it in a server. If you don’t mention it, it doesn’t jump in. It’s not that friend.

02

Text and images

Type like a normal person. Drop a picture if you want it to look at something and react.

03

A persona you can edit

The whole personality lives in one file. Change it, send a message, new voice. No restart needed.

04

Memory that sticks

Recent messages, short summaries, and a few facts about you live in a local SQLite file. Restarting the bot doesn’t wipe the chat.

05

Replies that hold

One request at a time per chat. Stale ones can get cancelled. It retries when things flake, and long replies get split so Discord doesn’t eat them.

06

Don’t spam it

25 AI requests per person every 45 seconds. Hit the cap and it tells you when to come back. Chill for a second.

It only talks if you DM it or mention it. It’s not sitting in every channel waiting to chime in.

04 / your data what it keeps, what it doesn’t

It remembers.
Be picky about that.

Memory is the whole point. It’s also your private chat. Both things can be true.

Messages live in a local SQLite database so the bot still has context after a restart. Fresh messages go to the model as they are. Older ones can get squeezed into a short summary plus a few stable facts.

Set MEMORY_RETENTION_DAYS if you want old raw messages cleaned up. Leave it at 0 and they stay until you delete them. That file can hold private conversations, so keep the host and backups private.

OpenAI calls use store: false. The background summary pass skips passwords, tokens, contact info, exact locations, medical or crisis stuff, and sexual details.

05 / setup three steps, then you talk

Set it up.
Then bother it.

Once Discord and the API key are in, using it is just… talking.

  1. Drop in the secrets.

    Put the Discord token and OpenAI key in .env. Not in git. Not in logs. Obvious, but people still do it.

  2. Run the bot.

    Use the launcher in the README. It makes a SQLite file under data/ and keeps it across restarts.

  3. Talk to it.

    Send a DM, or mention owaua in a server. Attach a picture if you want. Use !nuke N only if you have the permission.

06 / faq the stuff people actually ask

Questions
people actually have.

Does owaua answer every server message?

No. It answers DMs and messages that mention it. Regular server chat that doesn’t ping it gets left alone.

Why didn’t it answer?

Make sure it was a DM or you actually mentioned it, Message Content Intent is on, and you haven’t hit the 25 request limit.

Are summaries the same as chat history?

No. Recent messages stay word for word. Older ones can get condensed into a summary and a few stable facts. The retention setting is what cleans up the raw messages.

Can I trust every AI answer?

No. It can be wrong, confident, and still wrong. Check anything that matters, and read drafts before you send them anywhere.

Where do I report a problem?

For setup help or something you can reproduce, hit the official server. Say what you tried and what happened. Don’t dump tokens or private chats in a public channel.

Can I change the personality?

Yes. Edit the text inside PERSONA in persona.py. The next message picks it up. No restart.
