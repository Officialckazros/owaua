# Code of Conduct

We want this project to be a place where people can ask questions, report problems, and contribute without being treated badly.

Be respectful. Do not harass, threaten, demean, dogpile, publish someone else's private information, or use slurs. Disagree with ideas directly and leave room for other people to learn.

Maintainers may edit, remove, or reject contributions and may restrict participation when behavior makes the project less safe or useful. If something needs attention, use the private contact path in [SECURITY.md](SECURITY.md) when public discussion would expose someone or make the situation worse.
