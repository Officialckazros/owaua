How it works

Talking to Owaua is deliberately simple. You do not need to memorize a command for normal conversation.

Mention it in a server

Send @owaua your message. In DMs, just type normally.

Give it context when you want

It can work with image attachments and text files, and it can remember useful facts when memory is enabled for you.

Use commands for specific jobs

Commands cover recaps, quotes, games, moderation, privacy, community features, server configuration, and more.

Confirm actions that change Discord

Tool-style actions such as moderation or role changes are permission checked and require confirmation before they run.

What it can do

Owaua is more than a chat box bolted onto Discord.

Conversation + memory

Chat through mentions or DMs, keep scoped memories, track relationships, and clear conversation state when you want a reset.

Community tools

AFK, reminders, highlights, tags, polls, ranks, giveaways, tickets, quotes, recaps, custom commands, and other server utilities.

Games + extras

Coin flips, dice, rock-paper-scissors, trivia, shipping, roast battles, cards, deck battles, animal media, Pokémon info, and more.

Moderation helpers

Cases, configured assistant actions, cleanup tools, role controls, server settings, and permission-aware confirmations.

Files, images + links

Read attached text files, understand attached images, and return useful links for things such as music and GitHub repositories.

Language + server personality

Set personal or server reply languages and configure the server persona without changing the rest of the bot.

Privacy and permissions

The bot separates normal conversation from actions that can change a server.

History is opt-in

Raw conversation history is off by default. Server context is only read when the relevant history setting is enabled and users have opted in.

Normal chat does not run tools

Mentions and DMs are for conversation. State-changing Discord actions go through dedicated, confirmation-gated flows.

You have controls

Privacy, memory, conversation reset, DM opt-out, Terms controls, export tools, and server configuration are exposed through commands.

Server owners can enable or disable modules, so some commands may not be available in every server.
