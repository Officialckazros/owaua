------------------------------------------------------------------------------
 TALKING TO IT (no prefix)
------------------------------------------------------------------------------
@SefBot <message>        Chat with it in a server (mention it).
<message>  (in a DM)     Chat with it in a direct message.
Attach image + mention   Vision model describes the image; brain uses it.
Attach .txt + mention    Model reads, analyzes, or summarizes the text file.
React 👍 / 👎 on a reply  Feedback — learns + adjusts bond with you.
Reply "correction: ..." Explicit correction stored in the exact scope.

Notes:
- Remembers facts about YOU (merged/deduped, importance-ranked).
- Raw conversation history is off by default and requires scoped opt-in.
- Per-user relationship score, private nickname, grudge.
- Reads only consented context when the guild history feature is enabled.
- Every reply is an embed. Never uses emoji in its text.
- One model for everything: DeepSeek V4 Flash via InferX (image vision uses a
  separate free multimodal model).

!language [name]         Set the language the bot replies to you in
                         (`!language hebrew`, `!language es`, `!language ja`).
                         `!language` shows current. `!language reset` clears
                         yours (falls back to the server default / English).
                         `!language list` shows known names/codes.
                         `!language server <name>` (manage server) sets a
                         default for people who haven't picked their own.
                         Alias: `!lang`  (also: slash `/language`, `/lang`)

!ckazros <anything>      Owner-only. Does whatever you ask. Standing orders
                         (example: `!ckazros speak in hebrew from now`) apply
                         to every later reply until `!ckazros clear`.
                         `!ckazros` / `status` lists orders; `undo` pops last.
                         (also: slash `/ckazros`)

Normal @mentions / DMs stay full chaotic SefBot. Only the !assistant command
drops the savage tone and answers as a clear, compliant helper for THAT reply
(roles, timeouts, nicknames, channels, factual answers, etc.). There is no
sticky on/off — the next @mention is chaotic again. Assistant actions render
one Confirm/Cancel proposal and recheck the exact permission and hierarchy;
ordinary mentions and DMs never run tools.

------------------------------------------------------------------------------
 AI ACTIONS (`/act` only — permission and confirmation gated)
------------------------------------------------------------------------------
  kick_user / ban_user / assign_role / remove_role / dm_user /
  list_roles / set_status / chart / react_message

Ordinary chat never runs tools. `/act` proposes one action, binds it to the
invoker/server/channel, and rechecks permissions and hierarchy on confirmation.

------------------------------------------------------------------------------
 OWNER TERMINAL (global shell — not Discord)
------------------------------------------------------------------------------
block access <user_id>   Hard-block a user from ALL bot interaction
                         (mentions, DMs, prefix cmds, slash, reactions).
                         Takes effect immediately; no restart.
block unblock <user_id>  Remove a live CLI block.
block list               Show live-blocked user ids.

tos break                List EVERY ToS auto-block + why, then pick who to
                         unblock. Unblocked users get a bot DM that they can
                         use the bot again.
tos break list           List ToS blocks only (no prompt).
tos break unblock <id>   Unblock one user + DM them access restored.
tos break unblock all    Unblock all ToS blocks (confirm) + DM each.
                         Pass --no-dm to skip the notify.

(Also: `PYTHONPATH=src python -m sefbot.block_cli access <user_id>` / `PYTHONPATH=src python -m sefbot.tos_cli break`
 from the project dir.)
